# 4D classic commands with an OOP equivalent

Classic 4D language commands and the class functions, properties or object-returning commands that can replace them.

Docs version: `latest` · Language: `en` · Commands: 170 (general 96, ORDA 74)

**Drop-in**: 1:1 replacement with the same semantics. **Refactor**: equivalent feature but a different model (e.g. document reference → `FileHandle`, arrays → collections, current selection → entity selection). **Partial**: the OOP API covers only part of the command.

Entries marked † have not been reviewed yet.
